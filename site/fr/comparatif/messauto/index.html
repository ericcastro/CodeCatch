CodeCatch vs MessAuto

Les deux apps récupèrent les codes de vérification de Messages et de Mail sur Mac, et marchent dans tous les navigateurs. MessAuto peut coller le code puis appuyer sur Retour à votre place. CodeCatch lit aussi Gmail, récupère les liens de connexion et garde un historique.

En bref : MessAuto est le meilleur choix si vous voulez un outil qui colle le code et appuie sur Retour. CodeCatch est le meilleur choix si vos codes arrivent dans Gmail, si vous recevez des liens de connexion ou si vous voulez retrouver un code plus tard.

Qu’est-ce que MessAuto ?

MessAuto est une app gratuite et open source pour la barre des menus du Mac, écrite en Rust par LeeeSe. Elle surveille les apps Messages et Mail. Quand un message contient un code de vérification, MessAuto le copie, et peut aussi le coller dans le champ où vous êtes, puis appuyer sur Retour.

Le projet, sous licence MIT, est apprécié : environ 1 600 étoiles sur GitHub en octobre 2026. La dernière version, la 1.3.0, est sortie en octobre 2025.

Ce que les deux apps partagent

  • Elles marchent dans toutes les apps. Aucune ne dépend du remplissage automatique du navigateur : Chrome, Arc, Firefox, Edge, tout fonctionne. Si c’est lui qui vous pose problème, lisez pourquoi Chrome sur Mac ne remplit pas les codes.
  • Elles lisent Messages et l’app Mail. Les codes SMS n’y arrivent qu’une fois le Transfert de SMS activé sur votre iPhone.
  • Elles demandent l’accès complet au disque. macOS l’exige avant qu’une app puisse lire Messages et Mail.
  • Elles sont open source et tournent sur votre Mac, sans compte.

Les points forts de MessAuto

  • Pas besoin de toucher au clavier. Auto Paste (collage automatique) met le code dans le champ, et Auto Return (Retour automatique) le valide. Vous n’avez rien à taper.
  • Le presse-papiers peut rester intact. En mode « Don’t Occupy Clipboard » (ne pas occuper le presse-papiers), MessAuto tape directement le code. Ce que vous aviez copié avant reste en place.
  • Une fenêtre près du curseur. Sa fenêtre flottante affiche le code à côté du pointeur.
  • Vos propres règles. Dans un fichier de configuration, vous modifiez les mots-clés et les motifs que MessAuto utilise pour repérer un code.

Les points forts de CodeCatch

  • Gmail et d’autres comptes, en direct. MessAuto ne lit que l’app Mail, et son README indique que les autres clients mail ne sont pas encore pris en charge. CodeCatch lit l’app Mail, et se connecte aussi à Gmail, à Outlook et à d’autres comptes directement. Vos e-mails restent en lecture seule.
  • Les liens de connexion. Beaucoup de services envoient désormais un lien à la place d’un code. CodeCatch affiche le lien à côté de vos codes, vous dit où il mène et vous prévient s’il pointe vers un autre site que celui de l’expéditeur.
  • L’historique. Codes et liens restent 7 jours dans le menu. Tapez un nom, appuyez sur Retour, et le code est de nouveau copié.
  • Les codes Bitwarden. CodeCatch affiche vos codes Bitwarden dans la barre des menus, verrouillés par Touch ID.
  • Moins d’autorisations par défaut. CodeCatch ne demande l’autorisation Accessibilité que si vous voulez qu’il tape les codes pour vous.
  • Une installation normale. CodeCatch est signé avec un Developer ID : il s’ouvre comme n’importe quelle app.

Avec l’autorisation Accessibilité, une app peut appuyer sur des touches dans d’autres apps. C’est ce qui rend le collage automatique possible, et c’est pour cela que CodeCatch la laisse désactivée tant que vous ne la demandez pas.

Installer l’une ou l’autre

Les deux se téléchargent sur GitHub. MessAuto n’est pas signé par un développeur identifié : la première fois, macOS refuse donc de l’ouvrir. Son README propose deux façons de contourner ce blocage : faire un clic droit sur l’app et choisir Ouvrir, ou désactiver la vérification pour toutes les apps dans Terminal.

Si vous installez MessAuto, passez par le clic droit. Désactiver la vérification avec spctl --master-disable retire cette protection pour toutes les apps de votre Mac, pas seulement pour une.

Passer de MessAuto à CodeCatch

  • Quittez MessAuto depuis son icône dans la barre des menus, pour que deux apps ne réagissent pas au même code.
  • Téléchargez CodeCatch et ouvrez-le. Il se loge dans la barre des menus.
  • Autorisez l’accès complet au disque. CodeCatch ouvre le bon réglage pour vous.
  • Ajoutez vos comptes mail. Activez Apple Mail, ou ajoutez Gmail, Outlook ou un autre compte.
  • Le collage automatique vous manque ? Dans les réglages de CodeCatch, activez Automatically Type Codes. macOS vous demandera alors l’autorisation Accessibilité.

Questions fréquentes

Qu’est-ce que MessAuto ?

MessAuto est une app gratuite et open source pour Mac. Elle trouve les codes de vérification dans les apps Messages et Mail et les met là où vous en avez besoin : elle peut copier le code, le coller pour vous et appuyer sur Retour.

MessAuto est-il gratuit ?

Oui. MessAuto est gratuit et open source, sous licence MIT. Vous le téléchargez depuis sa page GitHub.

MessAuto fonctionne-t-il avec Gmail ?

Seulement si votre compte Gmail est configuré dans l’app Mail du Mac. MessAuto lit l’app Mail, pas Gmail directement, et son README indique que les autres clients mail ne sont pas encore pris en charge. CodeCatch lit aussi l’app Mail, et peut en plus se connecter directement à Gmail et à d’autres comptes.

MessAuto fonctionne-t-il dans Chrome ?

Oui. Comme CodeCatch, il passe par le presse-papiers et le clavier : le navigateur n’a donc pas d’importance. Les deux fonctionnent dans Chrome, Arc, Firefox, Edge et toute autre app.

Quelles autorisations demande chaque app ?

Les deux ont besoin de l’accès complet au disque, car macOS l’exige avant qu’une app puisse lire Messages et Mail. Le README de MessAuto cite aussi l’autorisation Accessibilité, qui permet à une app de taper dans d’autres apps. CodeCatch ne la demande que si vous activez la saisie des codes à votre place.

Peut-on utiliser MessAuto et CodeCatch en même temps ?

Oui, mais les deux réagiront au même code. Si vous gardez les deux, laissez le collage à une seule : Auto Paste activé dans MessAuto et la saisie désactivée dans CodeCatch, ou l’inverse.

Quelle alternative à MessAuto choisir ?

Si vous voulez ce que fait MessAuto, plus Gmail, les liens de connexion, un historique avec recherche et les codes Bitwarden, essayez CodeCatch. Si vos codes arrivent uniquement par SMS, 2FHey est une autre option open source.
