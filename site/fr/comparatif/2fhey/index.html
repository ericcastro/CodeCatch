En bref : 2FHey est le meilleur choix si vos codes arrivent uniquement par SMS, ou si vous utilisez Google Messages. CodeCatch est le meilleur choix si vous recevez aussi des codes par e-mail ou des liens de connexion, ou si vous voulez retrouver un code plus tard.

Qu’est-ce que 2FHey ?

2FHey est une app open source pour la barre des menus du Mac, écrite en Swift par SoFriendly. Elle surveille les SMS qui arrivent. Quand l’un d’eux contient un code de vérification, 2FHey copie le code et affiche une notification. Vous pouvez alors le coller dans n’importe quel navigateur.

Elle fait une seule chose et reste légère : selon son site, l’app pèse moins de 10 Mo. Son code est sur GitHub, où il recevait encore des mises à jour en août 2026.

Ce que les deux apps partagent

  • Elles marchent dans toutes les apps. Les deux copient le code dans le presse-papiers : il se colle donc dans Chrome, Arc, Firefox ou Edge. Aucune ne dépend du remplissage automatique du navigateur. Si c’est lui qui vous pose problème, lisez pourquoi Chrome sur Mac ne remplit pas les codes.
  • Elles lisent les iMessage et les SMS dans l’app Messages de votre Mac.
  • Elles demandent l’accès complet au disque. macOS l’exige avant qu’une app puisse lire Messages.
  • Elles peuvent coller le code pour vous, si vous activez l’option.
  • Elles sont open source et tournent sur votre Mac, sans compte.

Les points forts de 2FHey

  • Google Messages. Son site cite Google Messages à côté d’iMessage. CodeCatch a besoin que le SMS arrive dans l’app Messages, et donc d’un iPhone.
  • Un raccourci pour récupérer le dernier code. ⇧⌘E relit vos messages et copie de nouveau le code le plus récent.
  • La simplicité. Aucun compte mail à ajouter, peu de réglages à apprendre.
  • Des règles de détection que chacun peut enrichir. Ses fichiers de mots-clés sont sur GitHub, et l’app télécharge les plus récents à chaque démarrage.

Les points forts de CodeCatch

  • Les codes par e-mail. 2FHey ne lit que les SMS. La lecture d’Apple Mail est une demande ouverte sur sa page GitHub depuis 2023. CodeCatch lit Apple Mail, et se connecte à Gmail, à Outlook et à d’autres comptes directement. Vos e-mails restent en lecture seule.
  • Les liens de connexion. Beaucoup de services envoient désormais un lien à la place d’un code. CodeCatch affiche le lien à côté de vos codes, vous dit où il mène et vous prévient s’il pointe vers un autre site que celui de l’expéditeur.
  • L’historique. Codes et liens restent 7 jours dans le menu. Tapez un nom, appuyez sur Retour, et le code est de nouveau copié.
  • Les codes Bitwarden. CodeCatch affiche vos codes Bitwarden dans la barre des menus, verrouillés par Touch ID.
  • Plus de langues. CodeCatch reconnaît les codes dans 35 langues. Le README de 2FHey en cite six.
  • Moins d’autorisations par défaut. CodeCatch ne demande l’autorisation Accessibilité que si vous voulez qu’il tape les codes pour vous.

Avec l’autorisation Accessibilité, une app peut appuyer sur des touches dans d’autres apps. C’est ce qui rend le collage automatique possible, et c’est pour cela que CodeCatch la laisse désactivée tant que vous ne la demandez pas.

Passer de 2FHey à CodeCatch

  • Quittez 2FHey depuis son icône dans la barre des menus, pour que deux apps ne copient pas le même code.
  • Téléchargez CodeCatch et ouvrez-le. Il se loge dans la barre des menus.
  • Autorisez l’accès complet au disque. CodeCatch ouvre le bon réglage pour vous.
  • Ajoutez vos comptes mail. Activez Apple Mail, ou ajoutez Gmail, Outlook ou un autre compte. C’est justement ce qui manque à 2FHey.
  • Vous utilisiez le collage automatique ? Dans les réglages de CodeCatch, activez Automatically Type Codes. macOS vous demandera alors l’autorisation Accessibilité.

Questions fréquentes

Qu’est-ce que 2FHey ?

2FHey est une app open source pour Mac. Elle repère les codes de vérification dans les SMS qui arrivent et les copie dans le presse-papiers. Vous les collez ensuite dans Chrome, Firefox, Arc ou toute autre app.

2FHey récupère-t-il les codes reçus par e-mail ?

Non. 2FHey ne lit que les SMS. La lecture des codes dans Apple Mail est une demande de fonctionnalité ouverte sur sa page GitHub depuis 2023. CodeCatch lit Apple Mail, Gmail et d’autres comptes mail.

2FHey fonctionne-t-il avec Google Messages ?

D’après son site, oui, en plus d’iMessage. CodeCatch lit l’app Messages de votre Mac : pour les codes SMS, il faut donc un iPhone avec le Transfert de SMS activé.

2FHey est-il gratuit ?

2FHey est open source, et son README indique que le téléchargement passe par Gumroad. Consultez son site pour connaître le prix actuel.

2FHey fonctionne-t-il dans Chrome et Firefox ?

Oui. Comme CodeCatch, il copie le code dans le presse-papiers : il fonctionne donc dans tous les navigateurs et toutes les apps.

Quelles autorisations demande chaque app ?

Les deux ont besoin de l’accès complet au disque pour lire Messages. Le README de 2FHey cite aussi l’autorisation Accessibilité, pour le collage automatique et son raccourci clavier. CodeCatch ne la demande que si vous activez la saisie des codes à votre place.

Peut-on utiliser 2FHey et CodeCatch en même temps ?

Oui, mais les deux copieront le même code SMS. Le plus simple : confiez les SMS à une seule des deux apps, et désactivez cette source dans l’autre.

Quelle alternative à 2FHey choisir ?

Si vous voulez ce que fait 2FHey, plus les codes par e-mail, les liens de connexion, un historique avec recherche et les codes Bitwarden, essayez CodeCatch. Si vous cherchez un outil qui lit aussi Apple Mail et colle le code pour vous, MessAuto est une autre option open source.

Choisissez 2FHey si

  • Vous utilisez Google Messages sur un téléphone Android
  • Vous voulez un outil simple, qui fait une seule chose
