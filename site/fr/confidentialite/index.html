Confidentialité

Ce que CodeCatch lit, ce qu’il conserve et à quoi il se connecte

CodeCatch n’a ni compte ni serveur. Il n’envoie jamais vos codes, vos messages ni vos e-mails nulle part.

UGPar Uros Gazvoda · Mis à jour le 10 octobre 2026

Ce qu’il lit

Seulement là où un code peut arriver

Vous choisissez chaque source, et vous pouvez désactiver n’importe laquelle. Les e-mails sont ouverts en lecture seule : rien n’est marqué comme lu, déplacé ou supprimé.

  • Les nouveaux messages reçus dans Messages
  • Les nouveaux e-mails des boîtes de réception que vous activez, jusqu’aux 256 premiers Ko de chaque message
  • Les identifiants Bitwarden que vous importez : nom, nom d’utilisateur, site et clé d’authentification

Sources

  • Gmail vous@gmail.com

Ce qu’il conserve

Les codes en mémoire, les secrets dans votre trousseau

Codes et liens ne sont jamais écrits sur le disque. Au démarrage, l’app les relit dans Messages et dans vos e-mails, sur 1, 7 ou 30 jours, selon votre choix.

  • Une trace des messages que vous avez écartés, sans le code ni le lien
  • Les logos des services, enregistrés une fois pour s’afficher vite

Ce à quoi il se connecte

Cinq connexions, et c’est tout

Aucun suivi d’utilisation, aucun rapport de plantage, aucune publicité. CodeCatch ne se connecte à Internet que pour ces cinq choses :

Votre serveur mail
Pour lire vos e-mails, seulement dans les boîtes de réception que vous activez.
Google ou Microsoft
Seulement si vous vous connectez avec l’un d’eux pour lire Gmail ou Outlook.
Bitwarden
Par l’outil de Bitwarden lui-même, quand vous importez vos identifiants.
Logos des services
Chargés via le service de favicons de Google, ou celui de DuckDuckGo quand Google n’a pas de logo net. Ces services voient votre adresse IP et le domaine du service. CodeCatch ne contacte jamais le site du service lui-même. Activés par défaut ; vous pouvez les désactiver dans Settings → Privacy.
Recherche de mises à jour
Une fois par jour, vers codecatch.app. Chaque vérification envoie un identifiant d’installation aléatoire, la version de l’app, la version de macOS et le modèle du Mac. Le serveur se sert de votre adresse IP pour noter votre pays, votre ville et votre fournisseur d’accès, mais n’enregistre jamais l’adresse. Ces données servent à compter combien de Mac utilisent CodeCatch, et avec quelle version. Elles ne contiennent jamais vos codes, vos messages, vos e-mails ni ce que vous faites dans l’app. Pour arrêter ces vérifications, désactivez Update Automatically dans Settings → General.

Ce qu’il ne fait jamais

Cinq engagements

Il n’envoie jamais vos messages à CodeCatch
Codes et messages sont traités sur votre Mac. Quand vous ouvrez un lien de connexion, son jeton part vers la destination que vous choisissez.
Il n’ouvre jamais un lien tout seul
Vous voyez où mène un lien de connexion, puis vous décidez.
Il ne tape jamais rien dans d’autres apps
Sauf si vous activez Automatically Type Codes. L’option est désactivée par défaut.
Il ne modifie jamais vos e-mails

Il ne garde jamais votre mot de passe principal

Les détails

Autorisations, ce qui reste et ce site

Autorisations

macOS exige l’accès complet au disque avant qu’une app puisse lire Messages et Mail. CodeCatch ne lit que ces deux-là.

L’autorisation Accessibilité n’est nécessaire que si vous activez Automatically Type Codes.

À l’écran et dans le presse-papiers

Les fenêtres de CodeCatch sont masquées pendant le partage et l’enregistrement d’écran. Les codes restent cachés jusqu’à ce que vous les déverrouilliez avec Touch ID ou le mot de passe de votre Mac.

Un code copié est effacé au bout de 90 secondes si le presse-papiers n’a pas changé entre-temps. Le presse-papiers universel est désactivé pour ces copies. CodeCatch demande aux gestionnaires de presse-papiers de ne pas les enregistrer, mais d’autres apps peuvent quand même lire le presse-papiers.

Connexion avec Google ou Microsoft

Si vous vous connectez avec Google ou Microsoft, CodeCatch obtient un accès en lecture seule à vos e-mails Gmail ou Outlook. Depuis votre Mac, il lit les nouveaux e-mails de votre boîte de réception pour y trouver les codes de vérification et les liens de connexion. Il n’envoie, ne supprime, ne déplace et n’étiquette jamais d’e-mail. Les e-mails sont traités en mémoire, et jamais envoyés à CodeCatch ni à personne d’autre. Le jeton de connexion reste dans votre trousseau. Supprimer le compte dans Settings → Sources met aussi fin à l’accès de CodeCatch chez Google. Chez Microsoft, retirez-le dans votre compte Microsoft, sous Confidentialité → Applications et services. Pour Google, vous pouvez aussi le retirer depuis votre compte Google.

L’utilisation par CodeCatch des informations reçues des API Google respecte les Règles relatives aux données utilisateur dans les services d’API Google, y compris les exigences d’utilisation limitée.

Agents et ligne de commande

Cette fonction est désactivée par défaut. Si vous l’activez dans Settings → Agents, des agents comme Claude Code peuvent demander un code avec l’outil codecatch. Cet outil communique avec l’app par un socket sur votre Mac, que personne d’autre que vous ne peut ouvrir, et jamais par le réseau. Chaque code demande votre Touch ID ou le mot de passe de votre Mac, sauf si vous avez autorisé ce site pour cette app, ou activé Allow All Without Asking.

Ce réglage et vos règles restent dans votre trousseau. Les 50 dernières demandes (quelle app, quel site, quel résultat ; jamais le code) restent dans les réglages de l’app jusqu’à ce que vous les effaciez.

Recent Emails

Si un e-mail ressemble à un e-mail de vérification mais qu’aucun code n’y a été trouvé, CodeCatch le garde pour que vous puissiez copier le code à la main : 20 e-mails au plus, pendant 30 minutes, en mémoire seulement.

Tout supprimer

Dans Settings → Sources, supprimez chaque compte mail, puis choisissez Remove Bitwarden Codes… pour Bitwarden. Quittez ensuite CodeCatch et placez-le dans la Corbeille.

Les réglages et les logos en cache restent sur le Mac.

Ce site

codecatch.app ne dépose aucun cookie et n’affiche aucune publicité. Il compte les visites avec Cloudflare Web Analytics : les pages vues, le site d’où vous venez, ainsi que votre navigateur, votre appareil et votre pays. Cet outil n’utilise pas de cookies et ne vous suit pas sur d’autres sites.

Les téléchargements, et les visites venues de liens avec des paramètres de campagne, sont aussi comptés sur codecatch.app : la page, les paramètres, le site d’où vous venez, votre système d’exploitation, ainsi que le pays, la ville et le fournisseur d’accès déduits de votre adresse IP. L’adresse elle-même n’est pas enregistrée.
