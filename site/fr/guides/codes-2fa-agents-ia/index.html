Vous demandez à Claude Code de se connecter à un site pour vérifier quelque chose. Il trouve la page, saisit votre adresse e-mail, clique sur Envoyer le code… et s’arrête là. Le code est sur votre téléphone, et l’agent ne peut pas le lire.

En bref : installez CodeCatch, activez Let Agents Ask for Codes dans Settings → Agents, puis cliquez sur Connect à côté de votre agent. Quand un site envoie un code, l’agent le demande à CodeCatch, et vous validez avec Touch ID.

Pourquoi les agents IA restent bloqués à la double authentification

La double authentification, ou authentification à deux facteurs, est faite pour bloquer quiconque n’a que votre mot de passe. C’est exactement la situation d’un agent : il sait utiliser le navigateur, mais le code arrive dans Messages ou dans votre boîte de réception. Alors il attend que vous tapiez le code, ou il abandonne.

Ce que fait CodeCatch

CodeCatch récupère déjà sur votre Mac les codes reçus dans Messages et par e-mail. Désormais, un agent peut lui en demander un avec une courte commande :

codecatch get github.com

CodeCatch attend le code de github.com, puis affiche une carte avec l’app qui le demande, l’expéditeur et l’heure. Vous cliquez sur Allow et confirmez avec Touch ID. L’agent reçoit le code et le saisit.

Configuration en trois étapes

  1. Installez CodeCatch et autorisez-le à lire Messages et vos e-mails, comme d’habitude.
  2. Ouvrez Settings → Agents et activez Let Agents Ask for Codes. La commande codecatch s’installe en même temps.
  3. Cliquez sur Connect à côté de Claude Code, Codex ou Cursor. CodeCatch ajoute une petite skill que l’agent ne lit que lorsqu’il a besoin d’un code. Pour les autres agents, copiez le texte sous Other Agents dans leurs instructions.

Un point vert signifie que l’agent est connecté. Cursor lit aussi les skills de Claude Code et de Codex : il est donc couvert dès que l’un des deux est connecté. Tant que Let Agents Ask for Codes est désactivé, le reste de la page est grisé et les agents ne peuvent rien demander.

Ce que vous contrôlez

  • Chaque code demande votre accord. Allow exige Touch ID ou le mot de passe de votre Mac, à chaque fois.
  • Always Allow vous évite la demande pour une app donnée, sur un site ou sur tous les sites.
  • Allow All Without Asking donne les codes à n’importe quel agent, sans rien demander. Pour l’activer, il faut aussi Touch ID.
  • Les liens de connexion ont leur propre interrupteur, désactivé par défaut, car un tel lien connecte l’agent à votre compte.
  • Les liens de réinitialisation du mot de passe ne vont jamais aux agents.

Comment l’accès reste sécurisé

  • La commande parle à CodeCatch par un socket que personne d’autre que vous ne peut ouvrir sur votre Mac. Rien ne passe par le réseau.
  • CodeCatch vérifie l’app qui fait la demande grâce à sa signature de code. De son côté, la commande vérifie qu’elle parle bien au vrai CodeCatch.
  • Un code ne compte que s’il vient du domaine du site lui-même. Un e-mail signé « GitHub » mais envoyé depuis un autre domaine ne compte pas comme le code GitHub.
  • Une seule demande à la fois. Trois refus de suite désactivent l’accès des agents. Les autorisations automatiques donnent au plus 20 codes par heure.
  • Request History montre quelle app a demandé un code pour quel site, et ce qui s’est passé. Le code lui-même n’y est jamais gardé.

Une limite, pour être honnête : si un programme a déjà l’autorisation Accès complet au disque, il peut lire Messages et Mail lui-même. CodeCatch ne peut pas l’en empêcher.

Pour les développeurs et les scripts

Ajoutez --json pour obtenir le code et ses détails en JSON, et --since pour ignorer les codes arrivés avant votre clic sur Envoyer le code :

T=$(date +%s)
# click "Send code" on the site, then:
codecatch get github.com --since $T --json

La commande attend le code jusqu’à 90 secondes, plus le temps qu’il vous faut pour valider. Le code de sortie dit au script quoi faire ensuite : 0 = OK, 2 = vous avez refusé, 3 = aucun code reçu, 4 = accès désactivé, 5 = pas validé à temps. Tout le reste est dans codecatch --help.

Questions fréquentes

Comment Claude Code peut-il obtenir un code 2FA ?

Installez CodeCatch, activez Let Agents Ask for Codes dans Settings → Agents, puis cliquez sur Connect à côté de Claude Code. Quand un site envoie un code, Claude Code le demande à CodeCatch, et vous validez avec Touch ID.

Un agent peut-il lire tous mes codes ?

Non. Un agent demande un seul site à la fois et reçoit un seul code, après votre accord. Il ne peut ni lister ni rechercher vos codes, et il ne voit jamais vos messages.

Est-ce que ça marche quand je ne suis pas devant le Mac ?

Seulement si vous l’autorisez. Choisissez Always Allow pour un site et une app, ou activez Allow All, et les codes partent sans demande, jusqu’à 20 par heure. Chacun reste visible dans Request History.

Quels agents sont compatibles ?

Claude Code, Codex et Cursor se connectent en un clic. Tout autre agent ou script capable de lancer une commande peut aussi s’en servir : collez les quelques lignes d’instructions dans ses paramètres.

Faut-il laisser CodeCatch ouvert ?

CodeCatch tourne dans la barre des menus. S’il n’est pas lancé, la commande l’ouvre.

Mes codes passent-ils par Internet ?

Non. La commande parle à CodeCatch par un socket que personne d’autre que vous ne peut ouvrir sur votre Mac. Rien ne passe par le réseau.

Un agent peut-il obtenir un lien de réinitialisation de mot de passe ?

Non. Les liens de réinitialisation ne vont jamais aux agents. Les liens de connexion non plus, sauf si vous activez Sign-In Links dans Settings → Agents.

Laissez votre agent terminer la connexion.
