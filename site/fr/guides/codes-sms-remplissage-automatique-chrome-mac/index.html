Codes SMS non remplis dans Chrome sur Mac

Pourquoi les codes reçus par SMS ne s’affichent pas dans Chrome et les autres navigateurs sur Mac, et comment y remédier.

Gratuit · macOS 15+

Sur iPhone, le code de vérification reçu par SMS s’affiche au-dessus du clavier. Sur Mac, le remplissage automatique (ou saisie automatique) des codes SMS est moins fiable. Dans Chrome, souvent, le code n’apparaît pas du tout. Voici pourquoi, et ce que vous pouvez faire.

En bref : avant macOS 26, seul Safari remplit les codes automatiquement. Sous macOS 26, installez la dernière mise à jour. Ou passez-vous du remplissage automatique et collez le code : ça marche partout.

Ce qui marche, et où

SafariChrome, Firefox, Arc, Edge
macOS 15 ou antérieurOuiNon
macOS 26.0 et 26.1OuiEn panne chez beaucoup
macOS 26.2 ou ultérieurOuiRéparé, selon des utilisateurs

Les deux dernières lignes viennent de témoignages d’utilisateurs, cités plus bas. Votre version peut se comporter autrement.

D’abord : quelle version de macOS avez-vous ?

Ouvrez menu Apple → À propos de ce Mac.

  • macOS 15 ou version antérieure : les codes ne se remplissent automatiquement que dans Safari. Chrome, Firefox, Arc et Edge ne les ont jamais proposés, donc rien n’est cassé. Passez directement à la méthode qui marche avec toutes les versions.
  • macOS 26 (Tahoe) : Apple a ouvert le remplissage automatique des codes aux autres navigateurs, comme l’a rapporté MacRumors. Puis la fonction a cessé de marcher chez beaucoup d’utilisateurs. Lisez la suite.

1. Vérifiez que le code arrive sur votre Mac

Ouvrez Messages sur votre Mac et demandez un nouveau code. Si le SMS n’y apparaît pas, aucun navigateur ne pourra le remplir.

Pour les codes envoyés par SMS, activez le transfert sur votre iPhone : Réglages → Apps → Messages → Transfert de SMS, puis activez votre Mac. Les deux appareils doivent utiliser le même compte Apple.

Si le SMS n’arrive toujours pas, ou si l’option Transfert de SMS n’apparaît pas, vérifiez ces points :

  • L’iPhone est allumé et connecté. C’est lui qui reçoit le SMS et le transfère.
  • Même compte Apple. Sur le Mac, ouvrez Messages → Réglages → iMessage. Le compte affiché doit être le même que sous Envoi et réception sur l’iPhone.
  • Votre Mac est activé dans la liste Transfert de SMS.
  • Pas d’option Transfert de SMS, ou votre Mac n’y figure pas : désactivez puis réactivez iMessage, touchez Envoi et réception et reconnectez-vous.
  • Messages sur iCloud est activé : le transfert est alors déjà actif pour ce Mac.
  • Toujours rien : redémarrez les deux appareils, installez les mises à jour et vérifiez la date et l’heure de votre Mac.

Sur le site de l’Assistance Apple : Transférer des SMS de votre iPhone vers d’autres appareils.

2. Mettez à jour macOS 26

Fin 2025, des utilisateurs du forum d’assistance d’Apple ont constaté que les codes n’apparaissaient plus dans Chrome, Firefox, Brave et Opera sous macOS 26, alors que Safari fonctionnait toujours. Ils ont ensuite indiqué qu’une version plus récente corrigeait le problème. Une discussion sur le forum de MacRumors indique que les codes sont revenus dans Chrome avec macOS 26.2.

Ouvrez donc Réglages Système → Général → Mise à jour de logiciels et installez ce qui est proposé.

3. Pistes signalées sur les forums, avec une mise en garde

  • Siri et Apple Intelligence. Certains ont vu les suggestions disparaître quand ces fonctions étaient désactivées, puis revenir après les avoir réactivées.
  • Un réglage dans Terminal. La discussion du forum cite un réglage caché qui rétablit le remplissage automatique sur les versions touchées. La même discussion indique qu’il a causé des ralentissements et des plantages dans les apps basées sur Chrome. Nous ne le recommandons donc pas : la mise à jour est la solution la plus sûre.
  • Un gestionnaire de mots de passe. Dans Chrome et Edge, 1Password et d’autres extensions du même genre peuvent afficher leur propre menu sur le champ du code et masquer la suggestion du Mac, selon certains utilisateurs. Si vous en utilisez un, c’est peut-être pour cela qu’aucun code n’apparaît.

Je n’ai pas testé ces pistes sur toutes les versions. Elles viennent des discussions citées plus haut.

Pourquoi certaines pages ne proposent jamais le code

Même si tout est bien configuré, le navigateur ne propose un code que dans un champ qu’il reconnaît comme champ de code. C’est au site de signaler ce champ au navigateur. Beaucoup ne le font pas, et aucune suggestion n’apparaît alors, ni dans Safari ni ailleurs. Vous n’y pouvez rien de votre côté.

4. La méthode qui marche avec toutes les versions

Le remplissage automatique dépend de votre version de macOS, de votre navigateur et de la page. Le collage, non. Si le code est déjà dans le presse-papiers, ⌘V fonctionne dans tous les navigateurs et toutes les apps.

C’est ce que fait CodeCatch. Il récupère le code dans Messages ou dans vos e-mails dès son arrivée, le copie et l’affiche dans une petite bannière. Il fonctionne sur macOS 15 ou version ultérieure.

Sans CodeCatch, vous pouvez faire la même chose à la main : ouvrez Messages sur votre Mac, double-cliquez sur le code, copiez-le, revenez à la page et collez-le.

Questions fréquentes

Pourquoi Safari remplit-il le code, et pas Chrome ?

Le remplissage automatique des codes est une fonction de macOS qu’Apple a d’abord intégrée à Safari. Les autres navigateurs n’y ont eu accès qu’avec macOS 26, et elle y est peu fiable.

Chrome remplit-il les codes SMS sous macOS 15 ?

Non. Sous macOS 15 et les versions antérieures, seul Safari remplit les codes automatiquement. Chrome, Firefox, Arc et Edge ne l’ont jamais fait : rien n’est cassé. Ce qui marche avec toutes les versions : copier le code et le coller avec ⌘V.

Faut-il un iPhone ?

Pour les codes envoyés par SMS, oui. L’iPhone reçoit le SMS et le transfère à votre Mac. Avec un téléphone Android, le SMS n’arrive jamais dans Messages sur le Mac. Ni le remplissage automatique ni CodeCatch ne peuvent alors le voir.

Comment activer le Transfert de SMS ?

Sur l’iPhone, ouvrez Réglages → Apps → Messages → Transfert de SMS, puis activez votre Mac. Les deux appareils doivent utiliser le même compte Apple. Si Messages sur iCloud est activé, le transfert est déjà actif pour ce Mac.

Et les codes envoyés par e-mail ?

macOS peut proposer les codes reçus dans l’app Mail, qui doit être ouverte pour recevoir les nouveaux messages. Il ne lit pas Gmail dans votre navigateur. CodeCatch lit Apple Mail lui aussi, mais il lit lui-même Gmail, Outlook et vos autres comptes : Mail peut donc rester fermé.

Le code arrive en retard sur mon Mac. Pourquoi ?

Les codes SMS arrivent d’abord sur votre iPhone, qui les transfère ensuite. L’iPhone doit donc être allumé et connecté. Laisser Messages ouvert sur le Mac aide aussi.

Peut-on laisser les codes se remplir tout seuls sans risque ?

Un code n’est pas plus sûr que la page où vous le saisissez. Avant d’en demander un, vérifiez la barre d’adresse. C’est vrai pour le remplissage automatique comme pour le collage.

Oubliez le remplissage automatique. Collez, tout simplement.
