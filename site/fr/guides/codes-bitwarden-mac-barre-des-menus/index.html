Gratuit · macOS 15+

Bitwarden peut garder les clés de vos codes de double authentification et générer pour vous les codes à six chiffres (TOTP). Sur Mac, vous avez quatre façons d’y accéder : l’extension de navigateur, l’app de bureau, Bitwarden CLI et la barre des menus avec CodeCatch. Les trois premières ne demandent rien d’autre que Bitwarden.

Bitwarden enregistre les clés d’authentification quelle que soit l’offre. Pour afficher les codes, il faut Premium ou une organisation avec une offre payante, d’après la page d’aide de Bitwarden (en anglais).

Comment fonctionnent ces codes

Quand vous activez la double authentification sur un service, il vous donne une clé secrète, en général sous forme de QR code. Une app d’authentification combine cette clé avec l’heure actuelle et en tire un code à six chiffres qui change toutes les 30 secondes. Tout ce qui détient la clé peut générer le code : votre téléphone, Bitwarden ou CodeCatch.

À ne pas confondre avec Bitwarden Authenticator, une app séparée pour téléphone. Ce guide parle des codes du gestionnaire de mots de passe Bitwarden lui-même.

1. L’extension de navigateur

C’est la méthode qui demande le moins d’effort. Quand l’extension remplit votre nom d’utilisateur et votre mot de passe, elle copie aussi le code. Il ne reste qu’à appuyer sur ⌘V dans le champ du code.

Si rien n’est copié, ouvrez l’extension et vérifiez Paramètres → Saisie automatique → Copier le TOTP automatiquement. Selon Bitwarden, l’option est activée par défaut.

2. L’app de bureau

Ouvrez l’identifiant dans l’app Bitwarden. Le code s’affiche dans l’élément, avec un compte à rebours. Cliquez dessus pour le copier.

Elle marche aussi pour les connexions hors du navigateur, mais il faut changer d’app et chercher l’identifiant à chaque fois.

3. La ligne de commande (Bitwarden CLI)

Une fois Bitwarden CLI installé et votre coffre déverrouillé :

bw get totp github.com

La commande affiche le code actuel. C’est pratique dans un script, moins quand le code expire au bout de 30 secondes.

4. La barre des menus, avec CodeCatch

CodeCatch met vos codes Bitwarden dans la barre des menus, à côté des codes reçus par SMS et par e-mail. Appuyez sur ⌃⌥⌘F, tapez un nom, puis appuyez sur Retour : le code est copié.

  1. Installez Bitwarden CLI : brew install bitwarden-cli
  2. Connectez-vous une fois dans Terminal : bw login
  3. Dans CodeCatch, ouvrez Settings → Sources → Bitwarden → Set Up… L’app vérifie chaque étape pour vous.
  4. Saisissez votre mot de passe principal, vérifiez la liste des identifiants, puis enregistrez.

Si vous modifiez ensuite des identifiants à double authentification dans Bitwarden, utilisez Refresh… au même endroit.

Une fois la configuration terminée, vous pouvez :

  • chercher par service, compte ou site ;
  • épingler les identifiants que vous utilisez le plus, pour les garder en haut ;
  • voir le temps restant sur chaque code avant qu’il change ;
  • utiliser aussi vos codes Steam.

Si la configuration bloque

  • « bw: command not found ». Bitwarden CLI n’est pas installé. Lancez brew install bitwarden-cli, ou téléchargez-le sur le site de Bitwarden.
  • « You are not logged in ». Lancez bw login dans Terminal. La commande gère aussi la double authentification de votre propre compte Bitwarden.
  • Mauvais serveur. Si votre compte est sur bitwarden.eu, choisissez-le à l’étape du serveur. Pour changer de serveur, il faut d’abord bw logout.
  • Vous avez modifié quelque chose dans Bitwarden ? Utilisez Refresh… Avant l’enregistrement, vous voyez ce qui a été ajouté, modifié et supprimé.

Ce que CodeCatch conserve, et le compromis

  • Pour chaque identifiant, CodeCatch enregistre le nom, le nom d’utilisateur, le site et la clé d’authentification dans le trousseau d’ouverture de session de votre Mac.
  • Les codes sont générés sur votre Mac. Aucune connexion n’est nécessaire.
  • Les codes restent masqués jusqu’à ce que vous déverrouilliez CodeCatch avec Touch ID ou le mot de passe de votre Mac. Ils se verrouillent à nouveau quand le Mac se met en veille.
  • Remove Bitwarden Codes… supprime les clés enregistrées. Votre coffre Bitwarden ne change pas.

Le compromis est simple : une copie de vos clés d’authentification se trouve désormais sur ce Mac, hors de Bitwarden. Si vous préférez les garder uniquement dans votre coffre, choisissez l’une des trois premières méthodes.

Laquelle choisir ?

  • Surtout dans le navigateur : l’extension.
  • De temps en temps, partout : l’app de bureau.
  • Dans des scripts : la ligne de commande.
  • Toute la journée, dans n’importe quelle app, avec vos codes SMS et e-mail au même endroit : CodeCatch.

Questions fréquentes

Qu’est-ce qu’un code TOTP Bitwarden ?

C’est un code de double authentification à six chiffres qui change toutes les 30 secondes. Bitwarden garde la clé secrète du service et calcule le code à partir de cette clé et de l’heure actuelle. Toutes les offres peuvent enregistrer la clé, mais pour afficher les codes, il faut Premium ou une organisation avec une offre payante.

CodeCatch enregistre-t-il mon mot de passe principal Bitwarden ?

Non. Il est transmis une seule fois à l’outil en ligne de commande de Bitwarden, qui déverrouille le coffre pour l’import, et il n’est pas conservé. Le coffre est ensuite verrouillé à nouveau.

Les codes marchent-ils sans connexion Internet ?

Oui. Votre Mac calcule chaque code à partir de la clé enregistrée et de l’heure actuelle. Rien n’est consulté en ligne.

Est-il prudent de garder mes codes à côté de mes mots de passe ?

C’est un compromis. Tout garder dans Bitwarden est pratique, mais quelqu’un qui entre dans votre coffre obtient les deux. Beaucoup de gens gardent leurs comptes les plus importants, comme leur messagerie et leur banque, dans une app d’authentification séparée, et utilisent Bitwarden pour le reste.

Pourquoi le code est-il différent de celui de mon téléphone ?

Les codes dépendent de l’heure. Si l’horloge de votre Mac n’est pas à l’heure, le code est faux. Activez Régler la date et l’heure automatiquement dans Réglages Système → Général → Date et heure.

Un identifiant manque dans CodeCatch. Pourquoi ?

Seuls les identifiants qui ont une clé d’authentification dans Bitwarden sont importés. Ajoutez la clé à l’identifiant dans Bitwarden, puis utilisez Refresh… dans CodeCatch.

J’utilise le serveur européen de Bitwarden. Est-ce que ça marche ?

Oui. La configuration comporte une étape pour choisir le serveur : bitwarden.com ou bitwarden.eu. Pour changer de serveur, lancez d’abord bw logout.
