En pocas palabras: instala CodeCatch, activa Let Agents Ask for Codes en Settings → Agents y haz clic en Connect junto a tu agente. Cuando un sitio envía un código, el agente se lo pide a CodeCatch y tú lo apruebas con Touch ID.

Por qué los agentes de IA se atascan en la 2FA

La autenticación en dos pasos existe para frenar a cualquiera que solo tenga tu contraseña. Y un agente está justo en esa situación: puede usar el navegador, pero el código llega a Mensajes o a tu bandeja de entrada. Así que se queda esperando a que escribas el código, o se rinde.

Cómo te ayuda CodeCatch

CodeCatch ya captura en tu Mac los códigos que llegan a Mensajes y a tu correo. Ahora un agente también puede pedirle uno con un comando corto:

codecatch get github.com

CodeCatch espera el código de github.com y luego te muestra una tarjeta con la app que lo pide, el remitente y la hora. Haces clic en Allow y confirmas con Touch ID. El agente recibe el código y lo escribe.

Configúralo en tres pasos

  1. Instala CodeCatch y dale acceso a Mensajes y a tu correo, como siempre.
  2. Abre Settings → Agents y activa Let Agents Ask for Codes. Esto también instala el comando codecatch.
  3. Haz clic en Connect junto a Claude Code, Codex o Cursor. Esto agrega una pequeña skill que el agente solo lee cuando necesita un código. Para otros agentes, copia el texto de Other Agents en sus instrucciones.

Lo que tú decides

  • Cada código te pide permiso. Allow necesita Touch ID o la contraseña de tu Mac, cada vez.
  • Always Allow deja de preguntar cuando una app pide el código de un sitio, o de cualquier sitio.
  • Allow All Without Asking deja que cualquier agente reciba códigos sin preguntarte. Para activarlo también hace falta Touch ID.
  • Los enlaces de acceso (magic links) tienen su propio interruptor y vienen desactivados, porque con un enlace el agente inicia sesión como tú.
  • Los enlaces para restablecer la contraseña nunca llegan a los agentes.

Por qué es seguro

  • El comando se comunica con CodeCatch a través de un socket que, en tu Mac, solo tú puedes abrir. Nada sale a la red.
  • CodeCatch identifica la app que pide el código por su firma de código, y el comando comprueba que se comunica con el CodeCatch real.
  • Un código solo cuenta si viene del dominio del propio sitio. Un correo que se hace llamar “GitHub” pero llega desde otro dominio no trae el código de GitHub.
  • Una solicitud a la vez. Tres rechazos seguidos desactivan el acceso de los agentes. Las reglas de permiso dan como máximo 20 códigos por hora.
  • Request History muestra qué app pidió el código de qué sitio y qué pasó. El código nunca se guarda ahí.

Eso sí, hay un límite: si un programa ya tiene Acceso total al disco, puede leer Mensajes y Mail por su cuenta. CodeCatch no puede impedirlo.

Para desarrolladores y scripts

Con --json recibes el código y sus detalles en JSON. Con --since se ignoran los códigos que llegaron antes de hacer clic en Enviar código:

T=$(date +%s)
# click "Send code" on the site, then:
codecatch get github.com --since $T --json

El comando espera el código hasta 90 segundos, más el tiempo que tardes en aprobarlo. El código de salida le dice al script qué hacer después: 0, todo bien; 2, lo rechazaste; 3, no llegó ningún código; 4, el acceso está desactivado; 5, no se aprobó a tiempo. codecatch --help explica el resto.

Preguntas frecuentes

¿Cómo consigue Claude Code un código 2FA?

Instala CodeCatch, activa Let Agents Ask for Codes en Settings → Agents y haz clic en Connect junto a Claude Code. Cuando un sitio envía un código de verificación, Claude Code se lo pide a CodeCatch y tú lo apruebas con Touch ID.

¿Un agente puede leer todos mis códigos?

No. Un agente pide el código de un solo sitio cada vez y recibe un solo código, después de que tú lo apruebes. No puede listar tus códigos ni buscar entre ellos, y nunca ve tus mensajes.

¿Funciona si me alejo de mi Mac?

Solo si tú lo permites. Si eliges Always Allow para un sitio y una app, o activas Allow All, los códigos salen sin preguntarte, hasta 20 por hora. Aun así, cada uno queda en Request History.

¿Qué agentes son compatibles?

Claude Code, Codex y Cursor se conectan con un clic. Cualquier otro agente o script que pueda ejecutar un comando también puede usarlo: pega las instrucciones cortas en su configuración.

¿Tengo que dejar CodeCatch abierto?

CodeCatch funciona desde la barra de menús. Si no está abierto, el comando lo abre.

¿Mis códigos pasan por internet?

No. El comando se comunica con CodeCatch a través de un socket que, en tu Mac, solo tú puedes abrir. Nada sale a la red.

¿Un agente puede recibir un enlace para restablecer la contraseña?

No. Los enlaces para restablecer la contraseña nunca llegan a los agentes. Los enlaces de acceso sí, pero solo si activas Sign-In Links en Settings → Agents.
