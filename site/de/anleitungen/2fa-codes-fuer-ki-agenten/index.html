Du sagst Claude Code, es soll sich bei einer Website anmelden und kurz etwas nachschauen. Der Agent findet die Seite, trägt deine E-Mail-Adresse ein, klickt auf Code senden. Dann geht nichts mehr. Der Code ist auf deinem Handy, und da kommt der Agent nicht dran.

Kurz gesagt: Installiere CodeCatch, schalte unter Settings → Agents Let Agents Ask for Codes ein und klicke neben deinem Agenten auf Connect. Schickt eine Website einen Code, fragt der Agent bei CodeCatch nach, und du gibst den Code per Touch ID frei.

Warum Agenten bei 2FA hängen bleiben

Zwei-Faktor-Authentifizierung soll jeden aufhalten, der nur dein Passwort hat. Ein Agent steckt genau in dieser Lage: Den Browser kann er bedienen, aber der Code landet in der Nachrichten-App oder in deinem Postfach. Also wartet er, bis du den Code eintippst, oder er gibt auf.

So hilft CodeCatch

CodeCatch fängt auf deinem Mac ohnehin Codes aus Nachrichten und Mail ab. Jetzt kann auch ein Agent mit einem kurzen Befehl danach fragen:

codecatch get github.com

CodeCatch wartet auf den Code von github.com und zeigt dir dann eine Karte: welche App fragt, wer den Code geschickt hat und wann. Du klickst auf Allow und bestätigst mit Touch ID. Der Agent bekommt den Code und trägt ihn ein.

In drei Schritten einrichten

  1. Installiere CodeCatch und richte es wie gewohnt für Nachrichten und Mail ein.
  2. Öffne Settings → Agents und schalte Let Agents Ask for Codes ein. Damit installierst du gleich auch den Befehl codecatch.
  3. Klicke neben Claude Code, Codex oder Cursor auf Connect. Das legt einen kleinen Skill an, den der Agent nur liest, wenn er einen Code braucht. Bei anderen Agenten kopierst du den Text unter Other Agents in ihre Anweisungen.

Ein grüner Punkt heißt: verbunden. Cursor liest auch die Skills von Claude Code und Codex und ist damit automatisch dabei, sobald einer der beiden verbunden ist. Solange Let Agents Ask for Codes aus ist, ist der Rest des Tabs ausgegraut, und Agenten können nicht fragen.

Was du in der Hand hast

  • Jeder Code braucht dein OK. Allow geht jedes Mal nur mit Touch ID oder deinem Mac-Passwort.
  • Always Allow spart dir die Abfrage für eine App, bei einer bestimmten Website oder bei allen.
  • Allow All Without Asking gibt jedem Agenten Codes ohne Abfrage heraus. Schon das Einschalten geht nur mit Touch ID.
  • Anmeldelinks (Magic Links) haben einen eigenen Schalter und sind standardmäßig aus, denn so ein Link meldet den Agenten als dich an.
  • Links zum Zurücksetzen des Passworts bekommt ein Agent nie.

So sichert CodeCatch das ab

  • Der Befehl verbindet sich mit CodeCatch über einen Socket, den auf deinem Mac nur du öffnen kannst. Nichts läuft übers Netzwerk.
  • CodeCatch prüft die anfragende App anhand ihrer Codesignatur. Umgekehrt prüft der Befehl, ob am anderen Ende wirklich CodeCatch sitzt.
  • Ein Code zählt nur, wenn er von der Domain der Website selbst kommt. Eine Mail, die sich „GitHub“ nennt, aber von einer anderen Domain stammt, liefert keinen GitHub-Code.
  • Es läuft immer nur eine Anfrage. Drei Ablehnungen hintereinander schalten den Zugriff für Agenten ab. Regeln wie Always Allow geben höchstens 20 Codes pro Stunde heraus.
  • Die Request History zeigt, welche App für welche Website einen Code wollte und was daraus wurde. Den Code selbst speichert sie nie.

Was CodeCatch nicht verhindern kann: Hat ein Programm schon Festplattenvollzugriff, kann es Nachrichten und Mail selbst lesen.

Für Entwickler und Skripte

Mit --json bekommst du den Code samt Details als JSON. Mit --since ignoriert der Befehl Codes, die schon vor deinem Klick auf Code senden da waren:

T=$(date +%s)
# click "Send code" on the site, then:
codecatch get github.com --since $T --json

Der Befehl wartet bis zu 90 Sekunden auf den Code, plus die Zeit für deine Freigabe. Am Exit-Code sieht dein Skript, wie es weitergeht: 0 = OK, 2 = von dir abgelehnt, 3 = kein Code angekommen, 4 = Zugriff aus, 5 = nicht rechtzeitig freigegeben. Den Rest zeigt codecatch --help.

Häufige Fragen

Wie kommt Claude Code an einen 2FA-Code?

Installiere CodeCatch, schalte unter Settings → Agents „Let Agents Ask for Codes“ ein und klicke neben Claude Code auf „Connect“. Schickt eine Website einen Code, fragt Claude Code bei CodeCatch nach, und du gibst den Code per Touch ID frei.

Kann ein Agent alle meine Codes lesen?

Nein. Ein Agent fragt immer nur für eine Website und bekommt genau einen Code, und zwar erst nach deiner Freigabe. Er kann deine Codes weder auflisten noch durchsuchen, und deine Nachrichten sieht er nie.

Funktioniert das, wenn ich nicht am Mac bin?

Nur wenn du es erlaubst. Setzt du eine Website für eine App auf „Always Allow“ oder schaltest du „Allow All“ ein, gibt CodeCatch Codes ohne Abfrage heraus, bis zu 20 pro Stunde. Jeden einzelnen siehst du trotzdem in der „Request History“.

Welche Agenten funktionieren damit?

Claude Code, Codex und Cursor verbindest du mit einem Klick. Auch jeder andere Agent und jedes Skript, das Befehle ausführen kann, lässt sich anbinden: Füge die kurze Anleitung in die Einstellungen ein.

Muss CodeCatch dafür laufen?

CodeCatch sitzt ohnehin in der Menüleiste. Läuft es gerade nicht, startet der Befehl die App.

Gehen meine Codes dabei übers Internet?

Nein. Der Befehl verbindet sich mit CodeCatch über einen Socket, den auf deinem Mac nur du öffnen kannst. Nichts läuft übers Netzwerk.

Kann ein Agent einen Link zum Zurücksetzen des Passworts bekommen?

Nein. Links zum Zurücksetzen des Passworts bekommt ein Agent nie. Anmeldelinks bekommt er nur, wenn du unter Settings → Agents „Sign-In Links“ einschaltest.
