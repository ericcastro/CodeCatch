Chrome am Mac füllt SMS-Codes nicht automatisch aus

Warum Chrome und andere Browser am Mac keine SMS-Codes vorschlagen – und was du dagegen tun kannst.

Kostenlos · macOS 15+

Am iPhone steht der Bestätigungscode aus einer SMS direkt über der Tastatur. Am Mac klappt das automatische Ausfüllen von SMS-Codes weniger zuverlässig, und in Chrome taucht der Code oft gar nicht auf. Hier erfährst du, woran das liegt und was hilft.

Kurz gesagt: Vor macOS 26 füllt nur Safari Codes automatisch aus. Unter macOS 26 installierst du am besten die neueste Version. Oder du verzichtest aufs automatische Ausfüllen und fügst den Code ein – das klappt überall.

Zuerst: Welches macOS hast du?

Das siehst du unter Apple-Menü → Über diesen Mac.

  • macOS 15 oder älter: Codes werden nur in Safari automatisch ausgefüllt. Chrome, Firefox, Arc und Edge konnten das hier noch nie – es ist also nichts kaputt. Spring direkt zur Lösung, die mit jeder Version klappt.
  • macOS 26 (Tahoe): Apple hat das automatische Ausfüllen von Codes für andere Browser geöffnet, wie MacRumors berichtete. Danach lief es bei vielen nicht mehr. Lies weiter.

1. Kommt der Code überhaupt am Mac an?

Öffne am Mac die App „Nachrichten“ und fordere einen neuen Code an. Taucht die SMS dort nicht auf, kann kein Browser den Code ausfüllen.

Damit SMS-Codes am Mac ankommen, muss das iPhone sie weiterleiten. Öffne dazu auf dem iPhone Einstellungen → Apps → Nachrichten → SMS-Weiterleitung und aktiviere deinen Mac. Beide Geräte müssen denselben Apple Account verwenden.

Kommt die SMS trotzdem nicht an oder fehlt „SMS-Weiterleitung“ ganz? Dann prüfe Folgendes:

  • Das iPhone ist an und online. Es empfängt die SMS und leitet sie weiter.
  • Derselbe Apple Account. Öffne auf dem Mac Nachrichten → Einstellungen → iMessage. Dort muss derselbe Account stehen wie unter Senden & Empfangen auf dem iPhone.
  • Dein Mac ist in der Liste unter SMS-Weiterleitung aktiviert.
  • „SMS-Weiterleitung“ fehlt oder dein Mac steht nicht in der Liste: Schalte iMessage aus und wieder ein. Tippe dann auf Senden & Empfangen und melde dich erneut an.
  • „Nachrichten in iCloud“ ist aktiv: Dann ist die Weiterleitung für diesen Mac schon eingeschaltet.
  • Immer noch nichts? Starte beide Geräte neu, installiere Updates und prüfe Datum und Uhrzeit auf deinem Mac.

Mehr dazu beim Apple Support: Textnachrichten vom iPhone an andere Geräte weiterleiten.

2. macOS 26 aktualisieren

Ende 2025 meldeten Nutzer in Apples Support-Forum, dass unter macOS 26 in Chrome, Firefox, Brave und Opera keine Codes mehr erschienen. In Safari klappte es weiter. Später hieß es dort, ein neueres Update habe den Fehler behoben. Laut einem Thread im MacRumors-Forum waren die Codes in Chrome mit macOS 26.2 wieder da.

Schau also unter Systemeinstellungen → Allgemein → Softwareupdate nach und installiere, was dort angeboten wird.

3. Tipps aus Foren – mit Vorsicht zu genießen

  • Siri und Apple Intelligence. Einige Nutzer schreiben, dass keine Vorschläge mehr kamen, solange beides aus war. Nach dem Einschalten waren sie wieder da.
  • Eine versteckte Terminal-Einstellung. Im Forumsthread steht eine Einstellung, die das automatische Ausfüllen auf betroffenen Versionen zurückbringt. Laut demselben Thread hat sie Chrome-basierte Apps aber langsam gemacht und abstürzen lassen. Wir raten deshalb davon ab – ein Update ist der sicherere Weg.

Ich habe diese Tipps nicht auf jeder macOS-Version ausprobiert. Sie stammen aus den oben verlinkten Threads.

Warum manche Seiten den Code nie anbieten

Auch wenn alles richtig eingerichtet ist: Der Browser schlägt einen Code nur in einem Feld vor, das er als Codefeld erkennt. Dazu muss die Website das Feld entsprechend kennzeichnen. Viele Seiten tun das nicht – dann kommt kein Vorschlag, weder in Safari noch anderswo. Daran kannst du selbst nichts ändern.

4. So klappt es mit jeder Version

Ob das automatische Ausfüllen klappt, hängt von macOS-Version, Browser und Website ab. Beim Einfügen ist das egal: Liegt der Code schon in der Zwischenablage, funktioniert ⌘V in jedem Browser und jeder App.

Genau das macht CodeCatch. Die App liest den Code aus „Nachrichten“ oder deinen E-Mails, sobald er ankommt, kopiert ihn und zeigt ihn in einem kleinen Banner. CodeCatch läuft unter macOS 15 oder neuer.

Ohne CodeCatch geht es auch von Hand: Öffne am Mac „Nachrichten“, doppelklicke auf den Code, kopiere ihn, wechsle zurück und füge ihn ein.

Fragen

Warum füllt Safari den Code aus, Chrome aber nicht?

Das automatische Ausfüllen von Codes ist eine Funktion von macOS, die Apple zuerst in Safari eingebaut hat. Andere Browser haben erst mit macOS 26 Zugriff bekommen, und dort lief es bisher nicht zuverlässig.

Füllt Chrome unter macOS 15 SMS-Codes automatisch aus?

Nein. Unter macOS 15 und älter füllt nur Safari Codes automatisch aus. Chrome, Firefox, Arc und Edge konnten das dort noch nie – es ist also nichts kaputt. Was mit jeder Version klappt: den Code kopieren und mit ⌘V einfügen.

Brauche ich dafür ein iPhone?

Für Codes per SMS ja. Das iPhone empfängt die SMS und leitet sie an deinen Mac weiter. Mit einem Android-Smartphone landet die SMS nie in „Nachrichten“ auf dem Mac. Dann sehen weder das automatische Ausfüllen noch CodeCatch den Code.

Wie schalte ich die SMS-Weiterleitung ein?

Öffne auf dem iPhone Einstellungen → Apps → Nachrichten → SMS-Weiterleitung und aktiviere deinen Mac. Beide Geräte müssen denselben Apple Account verwenden. Ist „Nachrichten in iCloud“ aktiv, ist die Weiterleitung für diesen Mac schon eingeschaltet.

Was ist mit Codes per E-Mail?

macOS kann in Safari Codes aus der App „Mail“ vorschlagen. Gmail im Browser liest macOS dagegen nicht. CodeCatch liest Apple Mail, Gmail und andere E-Mail-Konten direkt.

Warum kommt der Code am Mac erst so spät an?

SMS-Codes landen zuerst auf deinem iPhone und werden dann weitergeleitet. Das iPhone muss eingeschaltet und online sein. Lass am besten „Nachrichten“ auf dem Mac geöffnet.

Ist es sicher, Codes automatisch ausfüllen zu lassen?

Ein Code ist nur so sicher wie die Seite, auf der du ihn eingibst. Prüfe die Adressleiste, bevor du einen Code anforderst. Das gilt beim automatischen Ausfüllen genauso wie beim Einfügen.
