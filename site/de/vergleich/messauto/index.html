MessAuto-Alternative: CodeCatch vs. MessAuto

Beide Apps fangen am Mac Bestätigungscodes aus „Nachrichten“ und „Mail“ ab und funktionieren in jedem Browser. MessAuto ist kostenlos und kann den Code automatisch einfügen und Return drücken. CodeCatch liest zusätzlich Gmail, erkennt Anmeldelinks und führt einen Verlauf.

Kurz gesagt: MessAuto ist die bessere Wahl, wenn du ein kostenloses Tool willst, das den Code einfügt und Return drückt. CodeCatch ist die bessere Wahl, wenn deine Codes in Gmail ankommen, Dienste dir Anmeldelinks schicken oder du einen Code später wiederfinden willst.

Was ist MessAuto?

MessAuto ist eine kostenlose Open-Source-App für die Menüleiste des Mac, von LeeeSe in Rust geschrieben. Sie achtet auf „Nachrichten“ und „Mail“. Steckt in einer Nachricht ein Bestätigungscode, kopiert MessAuto ihn. Auf Wunsch fügt die App ihn auch gleich in das Feld ein, in dem du gerade bist, und drückt Return.

Das Projekt ist beliebt: Im Oktober 2026 hatte es auf GitHub rund 1.600 Sterne. Es steht unter der MIT-Lizenz, die neueste Version 1.3.0 erschien im Oktober 2025.

Was beide Apps gemeinsam haben

  • Beide funktionieren in jeder App. Auf das automatische Ausfüllen des Browsers ist keine der beiden angewiesen, deshalb klappt es in Chrome, Arc, Firefox und Edge gleichermaßen. Hakt es bei dir genau daran, lies, warum Chrome am Mac Codes nicht automatisch ausfüllt.
  • Beide lesen „Nachrichten“ und „Mail“. SMS-Codes kommen aber erst an, wenn du auf dem iPhone die SMS-Weiterleitung einschaltest.
  • Beide brauchen Festplattenvollzugriff. Ohne ihn lässt macOS keine App an deine Nachrichten und E-Mails.
  • Beide sind Open Source, laufen auf deinem Mac und kommen ohne Konto aus.

Wo MessAuto stärker ist

  • MessAuto ist kostenlos.
  • Eingabe ohne dein Zutun. Auto Paste fügt den Code ins Feld ein, Auto Return schickt ihn ab. Die Tastatur musst du dafür nicht anfassen.
  • Die Zwischenablage bleibt auf Wunsch unberührt. Im Modus „Don’t Occupy Clipboard“ tippt MessAuto den Code direkt ein. Was du vorher kopiert hast, bleibt erhalten.
  • Code am Mauszeiger. Ein schwebendes Fenster zeigt den Code direkt neben dem Zeiger.
  • Eigene Regeln. In einer Konfigurationsdatei kannst du die Schlüsselwörter und Muster bearbeiten, an denen MessAuto einen Code erkennt.

Wo CodeCatch stärker ist

  • Gmail und andere Konten direkt. MessAuto liest nur „Mail“, andere Mail-Programme führt die README als noch nicht unterstützt. CodeCatch liest ebenfalls „Mail“, bindet aber zusätzlich Gmail und andere Konten direkt per App-Passwort an. Dabei greift es nur lesend auf deine Mails zu.
  • Anmeldelinks. Viele Dienste schicken heute statt eines Codes einen Link. CodeCatch zeigt ihn neben deinen Codes, sagt dir, wohin er führt, und warnt dich, wenn das Ziel nicht die Website des Absenders ist.
  • Verlauf. Codes und Links bleiben sieben Tage im Menü. Namen eintippen, Return drücken, und der Code ist wieder kopiert.
  • Bitwarden-Codes. CodeCatch zeigt deine Bitwarden-Codes in der Menüleiste, per Touch ID geschützt.
  • Weniger Berechtigungen ab Werk. Zugriff auf die Bedienungshilfen will CodeCatch nur, wenn es Codes für dich eintippen soll.
  • Installation wie gewohnt. CodeCatch ist mit einer Developer ID signiert und öffnet sich wie jede andere App.

Eine App mit Zugriff auf die Bedienungshilfen kann in anderen Apps Tasten drücken. Nur so funktioniert automatisches Einfügen. Genau deshalb bleibt dieser Zugriff bei CodeCatch aus, bis du ihn selbst einschaltest.

So installierst du die beiden Apps

Beide lädst du von GitHub herunter. MessAuto ist nicht von einem verifizierten Entwickler signiert, deshalb verweigert macOS beim ersten Start das Öffnen. Die README nennt zwei Auswege: Rechtsklick auf die App und „Öffnen“ wählen, oder die Prüfung im Terminal für alle Apps abschalten.

Nimm für MessAuto den Weg per Rechtsklick. Wer die Prüfung mit spctl --master-disable abschaltet, verliert diesen Schutz für jede App auf dem Mac, nicht nur für eine.

Von MessAuto zu CodeCatch wechseln

  • Beende MessAuto über sein Symbol in der Menüleiste, damit nicht zwei Apps auf denselben Code reagieren.
  • Lade CodeCatch herunter und öffne die App. Sie erscheint in der Menüleiste.
  • Erlaube den Festplattenvollzugriff. CodeCatch öffnet die passende Einstellung für dich.
  • Richte Mail ein. Schalte Apple Mail ein oder füge Gmail per App-Passwort hinzu.
  • Fehlt dir das automatische Einfügen? Dann schalte in CodeCatch unter Settings → General Automatically Type Codes ein. macOS fragt anschließend nach dem Zugriff auf die Bedienungshilfen.

Häufige Fragen

Was ist MessAuto?

MessAuto ist eine kostenlose Open-Source-App für den Mac. Sie findet Bestätigungscodes in den Apps „Nachrichten“ und „Mail“ und bringt sie dorthin, wo du sie brauchst. Sie kann den Code kopieren, für dich einfügen und Return drücken.

Ist MessAuto kostenlos?

Ja. MessAuto ist kostenlos und steht als Open Source unter der MIT-Lizenz. Du lädst es über seine GitHub-Seite herunter.

Funktioniert MessAuto mit Gmail?

Nur wenn dein Gmail-Konto in der App „Mail“ auf dem Mac eingerichtet ist. MessAuto liest „Mail“, nicht Gmail selbst, und andere Mail-Programme führt die README als noch nicht unterstützt. CodeCatch liest ebenfalls „Mail“ und kann sich außerdem direkt mit Gmail und anderen Konten verbinden.

Funktioniert MessAuto in Chrome?

Ja. Wie CodeCatch arbeitet es über Zwischenablage und Tastatur, der Browser spielt also keine Rolle. Beide funktionieren in Chrome, Arc, Firefox, Edge und jeder anderen App.

Welche Berechtigungen brauchen die beiden Apps?

Beide brauchen Festplattenvollzugriff, denn ohne ihn darf unter macOS keine App deine Nachrichten und E-Mails lesen. Die README von MessAuto nennt außerdem den Zugriff auf die Bedienungshilfen, mit dem eine App in andere Apps tippen kann. CodeCatch fragt nur dann nach den Bedienungshilfen, wenn du die automatische Eingabe von Codes einschaltest.

Kann ich MessAuto und CodeCatch zusammen nutzen?

Ja, aber dann reagieren beide auf denselben Code. Überlass das Einfügen deshalb einer der beiden: Lass Auto Paste in MessAuto an und die automatische Eingabe in CodeCatch aus, oder umgekehrt.

Was ist eine gute MessAuto-Alternative?

Willst du alles, was MessAuto kann, und dazu Gmail, Anmeldelinks, einen durchsuchbaren Verlauf und Bitwarden-Codes, dann probier CodeCatch. Kommen deine Codes nur per Textnachricht, ist 2FHey eine weitere Open-Source-Alternative.
