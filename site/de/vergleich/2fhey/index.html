2FHey-Alternative: CodeCatch vs. 2FHey

Beide Apps kopieren Bestätigungscodes aus „Nachrichten“, damit du sie in jedem Browser einfügen kannst. 2FHey beschränkt sich auf Textnachrichten. CodeCatch liest zusätzlich deine E-Mails, erkennt Anmeldelinks, führt einen Verlauf und lässt sich per Touch ID sperren.

Kurz gesagt: 2FHey ist die bessere Wahl, wenn deine Codes nur per Textnachricht kommen oder du Google Messages nutzt. CodeCatch ist die bessere Wahl, wenn Codes auch per E-Mail eintreffen, Dienste dir Anmeldelinks schicken oder du einen Code später wiederfinden willst.

Was ist 2FHey?

2FHey ist eine Open-Source-App für die Menüleiste des Mac, von SoFriendly in Swift geschrieben. Sie achtet auf eingehende Textnachrichten. Steckt in einer davon ein Bestätigungscode, kopiert 2FHey ihn und meldet das per Mitteilung. Einfügen kannst du den Code dann in jedem Browser.

Die App hat genau eine Aufgabe und ist entsprechend schlank: Laut Website ist sie keine 10 MB groß. Der Quellcode liegt auf GitHub und wurde dort noch im August 2026 aktualisiert.

Was beide Apps gemeinsam haben

  • Beide funktionieren in jeder App. Sie legen den Code in die Zwischenablage, deshalb klappt es in Chrome, Arc, Firefox und Edge gleichermaßen. Auf das automatische Ausfüllen des Browsers ist keine der beiden angewiesen. Hakt es bei dir genau daran, lies, warum Chrome am Mac Codes nicht automatisch ausfüllt.
  • Beide lesen iMessage und SMS aus „Nachrichten“ auf deinem Mac.
  • Beide brauchen Festplattenvollzugriff. Ohne ihn lässt macOS keine App an deine Nachrichten.
  • Beide können den Code automatisch einfügen, wenn du das einschaltest.
  • Beide sind Open Source, laufen auf deinem Mac und kommen ohne Konto aus.

Wo 2FHey stärker ist

  • Google Messages. Die Website von 2FHey nennt neben iMessage auch Google Messages. Bei CodeCatch muss die SMS in „Nachrichten“ auf dem Mac landen, und das setzt ein iPhone voraus.
  • Tastenkürzel für den letzten Code. ⇧⌘E liest deine Nachrichten erneut und kopiert den neuesten Code noch einmal.
  • Einfach gehalten. Es gibt keine Mail-Konten einzurichten und nur wenige Einstellungen.
  • Offene Erkennungsregeln. Die Schlüsselwortdateien liegen auf GitHub, und jeder kann sie erweitern. Die App lädt bei jedem Start die neueste Fassung.

Wo CodeCatch stärker ist

  • Codes aus E-Mails. 2FHey liest nur Textnachrichten. Unterstützung für Apple Mail ist seit 2023 ein offener Wunsch auf seiner GitHub-Seite. CodeCatch liest Apple Mail und bindet Gmail und andere Konten per App-Passwort an. Dabei greift es nur lesend auf deine Mails zu.
  • Anmeldelinks. Viele Dienste schicken heute statt eines Codes einen Link. CodeCatch zeigt ihn neben deinen Codes, sagt dir, wohin er führt, und warnt dich, wenn das Ziel nicht die Website des Absenders ist.
  • Verlauf. Codes und Links bleiben sieben Tage im Menü. Namen eintippen, Return drücken, und der Code ist wieder kopiert.
  • Bitwarden-Codes. CodeCatch zeigt deine Bitwarden-Codes in der Menüleiste, per Touch ID geschützt.
  • Mehr Sprachen. CodeCatch erkennt Codes in 35 Sprachen, die README von 2FHey nennt sechs.
  • Weniger Berechtigungen ab Werk. Zugriff auf die Bedienungshilfen will CodeCatch nur, wenn es Codes für dich eintippen soll.

Eine App mit Zugriff auf die Bedienungshilfen kann in anderen Apps Tasten drücken. Nur so funktioniert automatisches Einfügen. Genau deshalb bleibt dieser Zugriff bei CodeCatch aus, bis du ihn selbst einschaltest.

Von 2FHey zu CodeCatch wechseln

  • Beende 2FHey über sein Symbol in der Menüleiste, damit nicht zwei Apps denselben Code kopieren.
  • Lade CodeCatch herunter und öffne die App. Sie erscheint in der Menüleiste.
  • Erlaube den Festplattenvollzugriff. CodeCatch öffnet die passende Einstellung für dich.
  • Richte Mail ein. Schalte Apple Mail ein oder füge Gmail per App-Passwort hinzu. Genau das fehlt 2FHey.
  • Automatisches Einfügen genutzt? Dann schalte in CodeCatch unter Settings → General Automatically Type Codes ein. macOS fragt anschließend nach dem Zugriff auf die Bedienungshilfen.

Häufige Fragen

Was ist 2FHey?

2FHey ist eine Open-Source-App für den Mac. Sie erkennt Bestätigungscodes in eingehenden Textnachrichten und kopiert sie in die Zwischenablage. So kannst du sie in Chrome, Firefox, Arc oder jeder anderen App einfügen.

Funktioniert 2FHey mit Codes aus E-Mails?

Nein. 2FHey liest nur Textnachrichten. Codes aus Apple Mail stehen seit 2023 als offener Funktionswunsch auf seiner GitHub-Seite. CodeCatch liest Apple Mail, Gmail und andere E-Mail-Konten.

Funktioniert 2FHey mit Google Messages?

Laut seiner Website ja, zusätzlich zu iMessage. CodeCatch liest „Nachrichten“ auf deinem Mac. Für SMS-Codes brauchst du deshalb ein iPhone mit eingeschalteter SMS-Weiterleitung.

Ist 2FHey kostenlos?

2FHey ist Open Source, und laut README läuft der Download über Gumroad. Den aktuellen Preis findest du auf der Website von 2FHey.

Funktioniert 2FHey in Chrome und Firefox?

Ja. Wie CodeCatch kopiert es den Code in die Zwischenablage. Es funktioniert also in jedem Browser und in jeder App.

Welche Berechtigungen brauchen die beiden Apps?

Beide brauchen Festplattenvollzugriff, um Nachrichten zu lesen. Die README von 2FHey nennt außerdem den Zugriff auf die Bedienungshilfen. Den braucht 2FHey für automatisches Einfügen und das Tastenkürzel. CodeCatch fragt nur dann nach den Bedienungshilfen, wenn du die automatische Eingabe von Codes einschaltest.

Kann ich 2FHey und CodeCatch zusammen nutzen?

Ja, aber dann kopieren beide Apps denselben Code aus deinen Textnachrichten. Am einfachsten teilst du die Arbeit auf: Eine App kümmert sich um Textnachrichten, in der anderen schaltest du diese Quelle aus.

Was ist eine gute 2FHey-Alternative?

Willst du alles, was 2FHey kann, und dazu Codes aus E-Mails, Anmeldelinks, einen durchsuchbaren Verlauf und Bitwarden-Codes, dann probier CodeCatch. Suchst du ein kostenloses Tool, das auch Apple Mail liest und den Code automatisch einfügt, ist MessAuto eine weitere Open-Source-Alternative.
