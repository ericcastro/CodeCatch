Resposta curta: o 2FHey é a melhor escolha se seus códigos só chegam por mensagem de texto ou se você usa o Google Messages. O CodeCatch é a melhor escolha se os códigos também chegam por e-mail, se você recebe links de login ou se quer achar um código de novo mais tarde.

O que é o 2FHey?

O 2FHey é um app de barra de menus para Mac, de código aberto, escrito em Swift pela SoFriendly. Ele fica de olho nas mensagens de texto que chegam. Quando uma delas traz um código de verificação, o 2FHey copia o código e mostra uma notificação. Aí é só colar em qualquer navegador.

Ele faz uma coisa só e continua leve: segundo o site, o app tem menos de 10 MB. O código está no GitHub, onde ainda recebia atualizações em agosto de 2026.

O que os dois apps têm em comum

  • Funcionam em qualquer app. Os dois colocam o código na área de transferência, então funcionam no Chrome, no Arc, no Firefox e no Edge. Nenhum depende do preenchimento automático do navegador. Se o seu problema é esse, veja por que o Chrome do Mac não preenche o código.
  • Leem iMessage e SMS do app Mensagens no seu Mac.
  • Precisam de Acesso Total ao Disco. O macOS exige essa permissão antes que qualquer app leia o Mensagens.
  • Podem colar por você, se você ativar essa opção.
  • São de código aberto e funcionam no seu Mac, sem conta.

Onde o 2FHey se sai melhor

  • Google Messages. O site do 2FHey lista o Google Messages ao lado do iMessage. O CodeCatch depende de a mensagem chegar ao app Mensagens, o que exige um iPhone.
  • Um atalho para pegar o último código. ⇧⌘E lê suas mensagens de novo e copia outra vez o código mais recente.
  • É simples. Não há contas de e-mail para adicionar e há poucos ajustes para aprender.
  • Regras de detecção que qualquer pessoa pode ampliar. Os arquivos de palavras-chave ficam no GitHub, e o app baixa os mais recentes toda vez que abre.

Onde o CodeCatch se sai melhor

  • Códigos por e-mail. O 2FHey só lê mensagens de texto. Ler o Apple Mail é um pedido em aberto na página dele no GitHub desde 2023. O CodeCatch lê o Apple Mail e se conecta ao Gmail, ao Outlook e a outras contas diretamente. O acesso ao e-mail é só de leitura.
  • Links de login. Muitos serviços agora mandam um link no lugar do código. O CodeCatch mostra o link junto com seus códigos, diz para onde ele leva e avisa se ele aponta para um site diferente do site do remetente.
  • Histórico. Códigos e links ficam no menu por sete dias. Digite um nome e aperte Return: o código é copiado de novo.
  • Códigos do Bitwarden. O CodeCatch mostra seus códigos do Bitwarden na barra de menus, protegidos com Touch ID.
  • Mais idiomas. O CodeCatch reconhece códigos em 35 idiomas. O README do 2FHey lista seis.
  • Menos permissões por padrão. O CodeCatch só pede acesso à Acessibilidade se você quiser que ele digite os códigos por você.

Com acesso à Acessibilidade, um app consegue apertar teclas em outros apps. É isso que permite colar o código automaticamente. E é por isso que o CodeCatch deixa esse acesso desligado até você pedir.

Como trocar o 2FHey pelo CodeCatch

  • Encerre o 2FHey pelo ícone dele na barra de menus, para que dois apps não copiem o mesmo código.
  • Baixe o CodeCatch e abra o app. Ele fica na barra de menus.
  • Permita o Acesso Total ao Disco. O CodeCatch abre o ajuste certo para você.
  • Adicione seu e-mail. Ative o Apple Mail ou adicione o Gmail, o Outlook ou outra conta. Essa é a parte que o 2FHey não tem.
  • Usava a colagem automática? No CodeCatch, ative Automatically Type Codes em Settings → General. Depois o macOS vai pedir acesso à Acessibilidade.

Perguntas frequentes

O que é o 2FHey?

O 2FHey é um app de código aberto para Mac. Ele encontra códigos de verificação nas mensagens de texto que chegam e copia esses códigos para a área de transferência. Aí é só colar no Chrome, no Firefox, no Arc ou em qualquer outro app.

O 2FHey funciona com códigos por e-mail?

Não. O 2FHey só lê mensagens de texto. Ler códigos do Apple Mail é um pedido de recurso em aberto na página dele no GitHub desde 2023. O CodeCatch lê o Apple Mail, o Gmail e outras contas de e-mail.

O 2FHey funciona com o Google Messages?

Segundo o site dele, sim, além do iMessage. O CodeCatch lê o app Mensagens no seu Mac. Por isso, para receber códigos por SMS, você precisa de um iPhone com o Encaminhamento de Mensagens ativado.

O 2FHey é grátis?

O 2FHey é de código aberto, e o README dele diz que o download é feito pelo Gumroad. Confira o preço atual no site do 2FHey.

O 2FHey funciona no Chrome e no Firefox?

Sim. Assim como o CodeCatch, ele copia o código para a área de transferência. Então funciona em qualquer navegador e em qualquer app.

Quais permissões cada app pede?

Os dois precisam de Acesso Total ao Disco para ler o Mensagens. O README do 2FHey também lista o acesso à Acessibilidade, para colar automaticamente e para o atalho de teclado. O CodeCatch só pede Acessibilidade se você ativar a digitação automática dos códigos.

Posso usar o 2FHey e o CodeCatch juntos?

Pode, mas os dois vão copiar o mesmo código que chegou por mensagem. Uma divisão simples: deixe um app cuidar das mensagens de texto e desative essa fonte no outro.

Qual é uma boa alternativa ao 2FHey?

Se você quer o que o 2FHey faz e também códigos por e-mail, links de login, histórico com busca e códigos do Bitwarden, experimente o CodeCatch. Se prefere uma ferramenta que também lê o Apple Mail e cola o código por você, o MessAuto é outra opção de código aberto.

Escolha o 2FHey se

  • seus códigos só chegam por mensagem de texto
  • você usa o Google Messages num celular Android
  • você quer um app simples para uma tarefa só
