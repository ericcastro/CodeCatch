Baixar para macOS

Grátis · macOS 15+

O Bitwarden pode guardar as chaves da verificação em duas etapas das suas contas e gerar para você os códigos de seis dígitos, os chamados códigos TOTP. No Mac, há quatro jeitos de ver esses códigos. Os três primeiros só precisam do próprio Bitwarden.

O Bitwarden guarda chaves do autenticador em qualquer plano. Para mostrar os códigos, é preciso ter o Premium ou um plano pago de organização, segundo a página de ajuda do Bitwarden (em inglês).

Como esses códigos funcionam

Quando você ativa a verificação em duas etapas num serviço, ele fornece uma chave secreta, normalmente num QR code. Um app autenticador combina essa chave com a hora atual e gera um código de seis dígitos que muda a cada 30 segundos. Quem tiver a chave gera o mesmo código: seu celular, o Bitwarden ou o CodeCatch.

Não confunda com o Bitwarden Authenticator: esse é um app separado do Bitwarden, para celular. Este guia trata dos códigos guardados no cofre do Bitwarden.

1. A extensão do navegador

É o jeito que dá menos trabalho. Quando a extensão preenche seu usuário e sua senha, ela também copia o código. É só pressionar ⌘V no campo do código.

Se nada for copiado, abra a extensão e confira Configurações → Preenchimento automático → Copiar TOTP automaticamente. Segundo o Bitwarden, essa opção já vem ativada.

2. O app para desktop

Abra a credencial no app do Bitwarden. O código aparece dentro do item, com uma contagem regressiva. Clique nele para copiar.

Funciona para logins fora do navegador, mas você precisa trocar de app e buscar a credencial toda vez.

3. A linha de comando

Com o Bitwarden CLI (a interface de linha de comando do Bitwarden) instalado e desbloqueado:

bw get totp github.com

Ele mostra o código atual. Serve bem em scripts, mas é pouco prático para um código que vence em 30 segundos.

4. A barra de menus, com o CodeCatch

O CodeCatch coloca seus códigos do Bitwarden na barra de menus, junto com os códigos que chegam por SMS e e-mail. Pressione ⌃⌥⌘F, digite um nome, aperte Return e pronto: o código está copiado.

  1. Instale o Bitwarden CLI: brew install bitwarden-cli
  2. Faça login uma vez no Terminal: bw login
  3. No CodeCatch, abra Settings → Sources → Bitwarden → Set Up… Ele confere cada passo para você.
  4. Digite sua senha principal, revise a lista de credenciais e salve.

Depois de mudar credenciais com 2FA no Bitwarden, use Refresh… no mesmo lugar.

Com tudo configurado:

  • Busque por serviço, conta ou site.
  • Fixe as credenciais que você mais usa, para que fiquem no topo.
  • Veja quanto tempo falta para cada código mudar.
  • Códigos do Steam também funcionam.

Se a configuração travar

  • “bw: command not found”. O Bitwarden CLI não está instalado. Rode brew install bitwarden-cli ou baixe pelo site do Bitwarden.
  • “You are not logged in”. Rode bw login no Terminal. Ele também cuida da verificação em duas etapas da sua própria conta do Bitwarden.
  • Servidor errado. Se a sua conta está no bitwarden.eu, escolha esse servidor no passo correspondente. Para trocar, rode bw logout antes.
  • Mudou algo no Bitwarden? Use Refresh… Você vê o que foi adicionado, alterado e removido antes de salvar.

O que o CodeCatch guarda e qual é a desvantagem

  • Ele salva o nome, o usuário, o site e a chave do autenticador de cada credencial nas chaves de início de sessão do Mac (Keychain).
  • Os códigos são gerados no seu Mac. Não precisa de conexão.
  • Os códigos ficam ocultos até você desbloquear com Touch ID ou a senha do Mac, e voltam a ficar bloqueados quando o Mac entra em repouso.
  • Remove Bitwarden Codes… apaga as chaves salvas. Seu cofre do Bitwarden não muda.

A desvantagem é simples: agora existe uma cópia das suas chaves do autenticador neste Mac, fora do Bitwarden. Se você prefere mantê-las só no cofre, use um dos três primeiros jeitos.

Qual escolher

  • Quase sempre no navegador: a extensão.
  • De vez em quando, em qualquer lugar: o app para desktop.
  • Em scripts: a linha de comando.
  • O dia todo, em qualquer app, junto com seus códigos de SMS e e-mail: o CodeCatch.

Perguntas frequentes

O que é um código TOTP?

É o código 2FA de seis dígitos que muda a cada 30 segundos. Um app autenticador gera esse código a partir de uma chave secreta e da hora atual. O Bitwarden guarda a chave em qualquer plano, mas só mostra os códigos com o Premium ou um plano pago de organização.

O CodeCatch salva minha senha principal do Bitwarden?

Não. Ela vai uma única vez para a ferramenta de linha de comando do próprio Bitwarden, que desbloqueia o cofre para a importação. A senha não fica guardada, e depois o cofre é bloqueado de novo.

Os códigos funcionam sem internet?

Sim. O código é calculado no seu Mac, a partir da chave salva e da hora atual. Nada é consultado online.

É seguro guardar os códigos junto com as senhas?

Tem prós e contras. Ter os dois no Bitwarden é prático, mas quem entrar no seu cofre leva os dois. Muita gente deixa as contas mais importantes, como e-mail e banco, num autenticador separado e usa o Bitwarden para o resto.

Por que o código é diferente do que aparece no meu celular?

Os códigos dependem da hora. Se o relógio do Mac estiver errado, o código sai errado. Ative Definir data e hora automaticamente em Ajustes do Sistema → Geral → Data e Hora.

Uma credencial não aparece no CodeCatch. Por quê?

Só são importadas as credenciais que têm chave do autenticador no Bitwarden. Adicione a chave à credencial no Bitwarden e depois use Refresh… no CodeCatch.

Uso o servidor europeu do Bitwarden. Funciona?

Sim. A configuração tem um passo para escolher o servidor: bitwarden.com ou bitwarden.eu. Para trocar de servidor, rode bw logout antes.
