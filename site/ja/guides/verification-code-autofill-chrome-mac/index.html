CodeCatch メッセージとメールの認証コードとログインリンクを、届いた瞬間にコピー。

Mac版をダウンロード

無料 · macOS 15以降

iPhoneなら、SMSで届いた認証コード（確認コード）がキーボードの上に出てきます。Macではそれほど安定せず、Chromeではまったく出てこないこともよくあります。原因と対処法をまとめました。

結論から言うと、macOS 26より前は、認証コードが自動入力されるのはSafariだけです。macOS 26なら、最新バージョンにアップデートしてください。自動入力に頼らずコードをペーストする方法なら、どこでも使えます。

ブラウザ別の対応状況

SafariChrome、Firefox、Arc、Edge
macOS 15以前対応非対応
macOS 26.0と26.1対応不具合の報告多数
macOS 26.2以降対応復旧の報告あり

表の下2行は、ユーザーの報告にもとづいています（リンクは後述）。環境によって結果が違うこともあります。

まず、macOSのバージョンを確認

アップルメニュー＞「このMacについて」を開きます。

  • macOS 15以前：認証コードが自動入力されるのはSafariだけです。Chrome、Firefox、Arc、Edgeでは最初から使えない機能なので、故障ではありません。どのバージョンでも使える方法に進んでください。
  • macOS 26（Tahoe）：MacRumorsが報じたとおり、Appleはほかのブラウザでも認証コードを自動入力できるようにしました。ところがその後、多くの人の環境で動かなくなりました。下の手順を順に確認してください。

1. 認証コードがMacに届くか確認

Macで「メッセージ」アプリを開き、サイトから新しいコードを送ってもらいます。そこにSMSが表示されなければ、どのブラウザでも自動入力できません。

SMSで届く認証コードをMacで受け取るには、iPhoneで転送をオンにします。「設定」＞「アプリ」＞「メッセージ」＞「テキストメッセージ転送」を開き、Macをオンにします。両方のデバイスで同じApple Accountを使っている必要があります。

それでも届かない、または「テキストメッセージ転送」が見当たらないときは、次を確認します。

  • iPhoneの電源が入っていて、ネットにつながっている。SMSを受け取って転送するのはiPhoneです。
  • 同じApple Accountを使っている。Macで「メッセージ」＞「設定」＞「iMessage」を開きます。そこにあるアカウントが、iPhoneの「送受信」にあるアカウントと一致している必要があります。
  • 「テキストメッセージ転送」の一覧で、Macがオンになっている。
  • 「テキストメッセージ転送」がない、または一覧にMacがない：iMessageをいったんオフにしてオンに戻し、「送受信」をタップしてサインインし直します。
  • 「iCloudにメッセージを保管」がオン：この場合、そのMacではすでに転送がオンになっています。
  • それでも届かない：両方のデバイスを再起動し、アップデートをインストールして、Macの日付と時刻を確認します。

Appleサポート：iPhoneからほかのデバイスにテキストメッセージを転送する

2. macOS 26をアップデート

2025年後半、Appleのサポートフォーラムで、macOS 26にしたらChrome、Firefox、Brave、Operaで認証コードが出なくなったという報告がありました。Safariでは問題なく使えていました。その後、新しいリリースで直ったと報告されています。MacRumorsのフォーラムにも、macOS 26.2でChromeにコードが出るようになったという書き込みがあります。

まずは「システム設定」＞「一般」＞「ソフトウェアアップデート」を開き、表示されたアップデートをインストールしてください。

3. 報告されている対処法（注意あり）

  • SiriとApple Intelligence。これらをオフにしていたら候補が出なくなり、オンに戻したら出るようになった、という声があります。
  • ターミナルでの設定。フォーラムのスレッドでは、問題のあるバージョンで自動入力を復活させる隠し設定が紹介されています。ただ、同じスレッドでChromeベースのアプリが重くなったり落ちたりしたとも報告されているので、おすすめしません。アップデートするほうが安全です。
  • パスワードマネージャー。ChromeやEdgeでは、1Passwordなどの拡張機能がコード入力欄に独自のメニューを出し、Macの候補を隠してしまうという報告があります。使っているなら、コードが出ない原因はそれかもしれません。

すべてのバージョンで試したわけではありません。上でリンクしたスレッドからの情報です。

コードが出ないページがある理由

設定がすべて正しくても、ブラウザが候補を出すのは、コードの入力欄だと認識できた欄だけです。その欄がワンタイムパスワード用であることは、ウェブサイト側がブラウザに伝えます。伝えていないサイトも多く、その場合はSafariでもほかのブラウザでも候補は出ません。ユーザー側で変えられることはありません。

4. どのバージョンでも使える方法

自動入力が使えるかどうかは、macOSのバージョン、ブラウザ、ページによって変わります。ペーストならその心配はありません。コードがクリップボードに入っていれば、⌘Vはどのブラウザでも、どのアプリでも使えます。

CodeCatchがしているのは、まさにこれです。「メッセージ」アプリやメールにコードが届くと読み取ってコピーし、小さなバナーで表示します。macOS 15以降で使えます。

CodeCatchがなくても、手作業で同じことができます。Macで「メッセージ」アプリを開き、コードをダブルクリックしてコピーし、元の画面に戻ってペーストします。

よくある質問

Safariでは自動入力されるのに、Chromeではされないのはなぜ？

認証コードの自動入力はmacOSの機能で、AppleはまずSafariに組み込みました。ほかのブラウザが使えるようになったのはmacOS 26からで、そこでも安定していません。

iPhoneは必要？

SMSで届くコードには必要です。iPhoneがSMSを受け取り、Macに転送します。Androidのスマートフォンでは、SMSがMacの「メッセージ」アプリに届かないので、自動入力でもCodeCatchでも読み取れません。

Macに認証コードが届かないときは？

SMSのコードなら、iPhoneの「設定」＞「アプリ」＞「メッセージ」＞「テキストメッセージ転送」でMacをオンにします。両方のデバイスで同じApple Accountを使っている必要があります。それでも届かなければ、両方を再起動し、アップデートをインストールして、Macの日付と時刻を確認してください。

メールで届くコードは？

macOSは、「メール」アプリに届いたコードを候補に出せます。ただし新しいメールを受け取るには、「メール」アプリを開いておく必要があります。ブラウザで開いたGmailは読みません。CodeCatchはApple Mailも読み、Gmail、Outlook、そのほかのアカウントは直接読むので、「メール」アプリは閉じたままでかまいません。

Macにコードが届くのが遅いのはなぜ？

SMSのコードはまずiPhoneに届き、そこからMacに転送されます。iPhoneの電源が入っていて、ネットにつながっている必要があります。Macで「メッセージ」アプリを開いたままにしておくと改善します。

コードが自動で入力されても安全？

コードの安全性は、入力先のページしだいです。コードを送ってもらう前に、アドレスバーを確認してください。自動入力でも、ペーストでも同じです。
