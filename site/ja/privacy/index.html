プライバシー

CodeCatchが読むもの、保存するもの、接続する先

CodeCatchにはアカウントもサーバーもありません。コードやメッセージ、メールを外部に送ることは一切ありません。

著者：Uros Gazvoda · 2026年10月11日更新

読むもの

コードが届く場所だけ

読み取り元はひとつずつ自分で選べて、いつでもオフにできます。メールは読み取り専用で開くため、既読にしたり、移動したり、削除したりすることはありません。

  • 「メッセージ」アプリの新着メッセージ
  • オンにした受信トレイの新着メール（1通につき先頭の256KBまで）
  • インポートしたBitwardenのログインアイテム（名前、ユーザー名、サイト、認証キー）

Sources

  • Messages iMessage and forwarded SMS
  • Apple Mail No sign-in needed
  • Gmail you@gmail.com
  • BitwardenNot set up

保存するもの

コードはメモリ、機密情報はキーチェーン

コードとリンクがディスクに書き込まれることはありません。アプリを起動するたびに、「メッセージ」とメールから読み直します。さかのぼる期間は1日、7日、30日から選べます。

  • 一覧から消したメッセージの記録（コードやリンクは含みません）
  • サービスのロゴ（すばやく表示するため、一度だけ保存）

保存場所

  • コードとリンクアプリを終了すると消えるメモリ
  • メッセージとメールの本文読むだけで保存しないなし
  • メールのパスワード送り先はメールサーバーだけキーチェーン
  • Bitwardenの認証キーMacの外に出ないキーチェーン
  • コピーしたコードユニバーサルクリップボードを使わない90秒

接続する先

接続先は5つ、これですべて

利用状況のトラッキング、クラッシュレポート、広告はありません。CodeCatchがインターネットにつなぐのは、次の5つだけです。

メールサーバー
メールを読むために接続します。対象はオンにした受信トレイだけです。
GoogleまたはMicrosoft
GmailやOutlookを読むために、GoogleやMicrosoftでログインした場合だけです。
Bitwarden
ログインアイテムをインポートするときに、Bitwarden公式のツールを通して接続します。
サービスのロゴ
Googleのfaviconサービスから読み込みます。Googleで鮮明なロゴが取れないときは、DuckDuckGoのサービスを使います。どちらにも、IPアドレスとサービスのドメインが伝わります。CodeCatchがサービス自体のWebサイトにアクセスすることはありません。ロゴの読み込みは初期設定でオンです。オフにするには「Settings」＞「Privacy」を開きます。
アップデートの確認
1日1回、codecatch.appに接続します。送るのは、ランダムなインストールID、アプリのバージョン、macOSのバージョン、Macの機種です。サーバーはIPアドレスから国、都市、インターネットプロバイダを記録しますが、IPアドレス自体は保存しません。CodeCatchが何台のMacで、どのバージョンで動いているかを数えるためのものです。コード、メッセージ、メール、アプリでの操作内容は一切含みません。止めるには、「Settings」＞「General」で「Update Automatically」をオフにします。

接続先

  • メールサーバーメールを読むためメールがオンのとき
  • GoogleまたはMicrosoftログインしたときだけ任意
  • BitwardenBitwarden公式のツール経由インポート時
  • サービスのロゴGoogleかDuckDuckGo経由、オフにできる
  • アップデートcodecatch.appから、1日1回

しないこと

必ず守る5つのこと

メッセージをCodeCatchにアップロードしない
コードとメッセージは、Macの中で処理します。ログインリンクを自分で開くと、リンクに含まれるトークンがそのリンク先に送られます。
勝手にリンクを開かない
ログインリンクのリンク先を確かめてから、開くかどうかを自分で決められます。
ほかのアプリに入力しない
「Automatically Type Codes」をオンにした場合は別です。初期設定ではオフです。
メールを書き換えない
既読にしたり、移動したり、削除したりはしません。
マスターパスワードを保存しない
Bitwardenのマスターパスワードは、インポートのときに一度使うだけです。

補足

権限、残るデータ、このサイトのこと

権限

フルディスクアクセスは、macOSでアプリが「メッセージ」と「メール」を読むために必要な許可です。CodeCatchが読むのはこの2つだけです。

アクセシビリティの許可が必要なのは、「Automatically Type Codes」をオンにした場合だけです。

画面とクリップボード

CodeCatchのウインドウは、画面共有や画面収録には映りません。コードは、Touch IDかMacのパスワードでロックを解除するまで隠れています。

コピーしたコードは、クリップボードが変わっていなければ90秒後に消去されます。このコピーではユニバーサルクリップボードを使いません。クリップボード管理アプリには保存しないよう求めますが、ほかのアプリがクリップボードを読むことはできます。

GoogleやMicrosoftでログイン

GoogleまたはMicrosoftでログインすると、CodeCatchはGmailやOutlookのメールを読み取り専用で利用できるようになります。Macから受信トレイの新着メールを読み、認証コードとログインリンクを探します。メールの送信、削除、移動、ラベル付けは一切しません。メールはメモリ上で処理し、CodeCatchにもほかの誰にも送りません。ログインのトークンはキーチェーンに保存されます。「Settings」＞「Sources」でアカウントを削除すると、Google側でのCodeCatchのアクセス権も取り消されます。Microsoftの場合は、Microsoftアカウントの「プライバシー」にある「データにアクセスできるアプリとサービス」から取り消してください。Googleのアクセス権は、Googleアカウントからも取り消せます。

CodeCatchがGoogle APIから受け取った情報の使用は、使用制限の要件を含め、Google API サービスのユーザーデータに関するポリシーに準拠します。

AIエージェントとコマンドライン

初期設定ではオフです。「Settings」＞「Agents」でオンにすると、Claude CodeなどのAIエージェントがcodecatchツールでコードを頼めるようになります。ツールとアプリのやりとりには、Mac上で自分だけが開けるソケットを使い、ネットワークは通りません。コードを渡すたびにTouch IDかMacのパスワードが必要です。ただし、そのアプリにそのサイトを許可した場合や、「Allow All Without Asking」をオンにした場合は除きます。

オン／オフの設定とルールはキーチェーンに保存されます。直近50件のリクエストの記録（アプリ、サイト、結果。コードは含みません）は、消去するまでアプリの設定に残ります。

Recent Emails

認証メールらしいのにコードが見つからなかったメールは、手でコードをコピーできるように残しておきます。最大20件、30分間、メモリ上だけです。

すべてを削除するには

「Settings」＞「Sources」でメールアカウントをひとつずつ削除し、Bitwardenは「Remove Bitwarden Codes…」を選びます。そのあとCodeCatchを終了して、ゴミ箱に入れます。

設定と、キャッシュされたロゴは残ります。

このサイトについて

codecatch.appはCookieを使わず、広告も表示しません。アクセス数はCloudflare Web Analyticsで数えています。記録するのは、閲覧したページ、参照元のサイト、ブラウザ、デバイス、国です。ほかのサイトでの行動を追跡することもありません。

ダウンロードと、キャンペーン用のタグが付いたリンクからのアクセスも、codecatch.appで数えています。記録するのは、ページ、タグ、参照元のサイト、OS、そしてIPアドレスから割り出した国、都市、インターネットプロバイダです。IPアドレス自体は保存しません。
